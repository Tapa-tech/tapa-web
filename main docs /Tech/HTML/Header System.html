SECTION 08
Locked rules

Decisions that should be inherited rather than re-litigated per article.

Dharma does not demand fear. It demands devotion.

LOCKED VERBATIM — announcement bar, all pages. No contractions, no em-dash, no added intensifiers. Functionally a wordmark.

RULE 01 · HERO
Plain gradient. No photography.

Hue is set by deity or category. Dark end always below 12% luminance on the title side, same three-stop structure every time. No hero image production line — the inline images carry the visual weight.

RULE 02 · NAV
A nav item must lead somewhere that works today.

Categories not yet open live in the footer sitemap band with a month attached, never in the header. Commerce icons appear only when there is something to buy. Beginner's Guides leads the Ritual Guides dropdown, ahead of the occasion sub-categories, because orientation precedes practice.

RULE 03 · DROPDOWNS
Four columns. Column four is always a feature card.

Column one is the entry point for a newcomer. Columns two and three are taxonomy and current content. Column four is never more links. Every dropdown closes with a one-line editorial footnote stating a principle — not a promotion.

RULE 04 · FOOTER
Taxonomy in the band, never in the columns.

Columns carry company, help, account and connect only. Every sub-category links to a real listing page or it does not appear. Pre-gate categories show a month, not a SOON pill. Mobile turns everything into accordions, one section open at a time.

RULE 05 · DPB
DHARMA ≥ 3/5 · PRATHA ≤ 2/5 · Panchang carries neither.

Every article shows Myths & Facts and a visible Dharma/Pratha separation. Never mixed in one paragraph. If you cannot name the text a reader could check, the answer is No. Addendum 14.1 and 14.2.

COPY
The three tests
Every line on the platform passes all three before it ships.
TEST 1 · FEAR

Does this line create, imply, or reinforce fear about ritual practice?

If yes → rewrite. Always.
TEST 2 · CLARITY

If a 40-year-old woman preparing for Hariyali Teej for the first time read this, would she know exactly what to do?

If no → rewrite.
TEST 3 · SOURCE

If challenged, can we point to a specific text, chapter, or section for this claim?

If no → do not make the claim.
